# Go2 避障：Mac 与 Taku Phone 离线集成结果

日期：2026-10-26（Asia/Shanghai）。分支：`codex/go2-avoidance-simulation`。
这是对 [此前六项审计](OFFLINE-AUDIT-2026-10-26.md) 的实现补齐；此前报告保留为历史基线。

本轮机器狗不在现场。所有运动测试使用独立模拟服务，未连接真实 Go2，未发送真实运动或模式切换指令。

## 六项结果

| 项目 | 本轮实现与证据 | 边界 |
| --- | --- | --- |
| 原生避障协议 | 独立 NativeTransport、严格响应类型与白名单、开启后回读、命令来源、受限 Move 和组合停止；与普通 Move 互斥 | 实机仅查询，写入没有开放入口；PRO 当前固件是否接受仍待实机 |
| 位姿和点云 | 保留 position、四元数、yaw、可用源时间；世界到机身变换、机身扫过范围、数据过期/坐标错配拒绝；5 项几何测试 | 实机 pose 默认未配准，不能假设与 LiDAR odom 同系；不是全局定位/导航 |
| 模拟服务 | 可独立启动的 Mac 服务，18 个场景；与手机共用真实 HTTP/UI；不导入机器人驱动，拒绝出站网络 | 简化平地运动学和机载拦截替身，不是宇树动力学或官方避障算法 |
| 控制状态机 | 设置回读、每次启用、固定短动作、执行中重查、心跳、控制权互斥、停止未确认锁定、取消竞争处理 | 软件 Stop 确认不等于物理停稳；实机失联与制动仍需测试 |
| Taku Phone | 新「避障」页、来源标识、局部俯视图、四方向门禁、场景注入、双语、固定停止、后台锁定；实际 API36 AVD 联调 | 是实际 Android WebView + 模拟后端，不是实机避障验收 |
| 录制回放 | 完整解码点云、位姿、状态、时间、动作/RPC 证据，JSONL 有界落盘；暂停/继续/结束；回放不执行指令 | 界面选择当前服务进程最后一次完成录制；重启后文件保留，尚无历史文件管理器 |

## Mac 验证

- `npm run check:go2:simulation`：**59 项 Python 测试通过**（原生控制 13、HTTP 8、点云 5、普通运动 11、几何 5、只读协议 5、录制 5、模拟集成 7）；微动 UI 10 项通过，前端与手机测试脚本语法检查通过。
- `npm test`：完整仓库 **74 项 Node 测试通过**，其中包含上面的 10 项 UI 测试，不重复计数。
- `npm run check:go2` 和 `npm run check` 通过。
- Android APK 使用现有 JDK 17 构建并通过签名检查，安装到已有 `TakuBase_API36_ARM64 / emulator-5554`，没有擦除账号和应用。
- 录制测试以 **64,000 个点**验证完整往返；损坏时间线、非有限数据、错误头、错误点长和文件超限显式失败。

合成几何性能：当前 Mac 上预热 5 次，再各运行 100 次；48,000 点中位 **5.846 ms**、P95 **7.271 ms**；64,000 点中位 **8.060 ms**、P95 **9.531 ms**。全部点通过高度/范围过滤并参与检查。这说明当前几何计算本身可支持继续联调；**不包含采集、网络、解码、HTTP、渲染或真实制动，不能据此承诺实机避障延迟**。复现：虚拟环境 Python 执行 `tooling/go2-lab/benchmark-perception.py`。

0.35 秒是动作持续时间。模拟感知约 10 Hz，执行过程约每 25 ms 重查，二者相互独立。真实接收频率、尾延迟、数据时钟和失联停止时间尚未取得本轮证据。

## Taku Phone 验证

测试脚本 `tooling/go2-lab/test-phone-simulation.mjs` 最终 **27 项通过，未捕获 JavaScript 运行异常**。它通过 CDP 操作实际应用 DOM，并通过 ADB 执行 Android HOME、恢复前台、移除/恢复回环通道和截图。测试每次操作前断言后端是模拟源。此数量不包含下方单列的未通过压力场景。

覆盖：来源标识与默认锁定；空旷四方向位姿变化；四方向障碍阻止；运动中障碍出现；模拟机载拦截；点云/位姿过期、空云、坐标不一致、模式变化；开启失败、回读不一致、无效状态、查询超时；停止未确认与显式恢复；Android 后台；手机通道中断与恢复不重启用；完整录制与暂停/继续只读回放；断连/重连；320/768/1024/1440 宽度及英文；完整点云 WebGL 绘制。

完整点云用例实际接收、上传和绘制均为 **6,616 点**，WebGL 无报错；该用例验证点数完整性，没有测持续帧率。

证据位于 ignored `out/go2-lab/phone-simulation/`：`results.json`、`final.png`、`controls.png`、`front-obstacle.png`、`stop-unconfirmed.png`、`replay.png` 和 `full-point-cloud.png`。未通过压力场景保留在 `reload-outage-failure.json` 与 `reload-outage-crash.log`。

额外修补和追踪了测试发现的问题：

1. 普通微动启用请求未返回时切后台/切页，原逻辑可能漏发停止。现在会取消并停止，晚到的启用响应不能覆盖停止；新增两项回归。
2. 错误页改为覆盖层，避免网络回调期间摘除 WebView。但反复执行“移除 ADB 回环通道后立即重载页面”仍偶发 `Chrome_IOThread` 的 `dangling raw_ptr` 原生崩溃，**未解决，不能算通过**。当前 AVD 使用 `com.android.webview 133.0.6943.137`。崩溃期间 Mac 心跳监控仍撤销了控制。最终常规断网用例保留页面，通过 CDP 网络离线加移除 ADB 回环通道验证；这与断网时强制重载是不同场景。后者需要进一步定位/升级 WebView 再验证，不能通过关闭内存检测规避。

## 狗回来后必须完成的验收

1. 只读记录型号、固件、运动模式、原生避障查询响应和传感器时间字段。
2. 在已知朝向与少量可控位移下验证四元数顺序、坐标轴、单位、sport pose 与 LiDAR odom 的变换关系。
3. 连续记录点云/位姿，统计间隔、P95/P99、停更、时间偏差；同步视频才能测采集到动作的端到端延迟。
4. 在现场看护下单独验证开启/关闭回读、API 控制来源、低速命令被原生避障拦截，以及普通控制不绕过保护。
5. 有实体停止手段时验证松手、软件 Stop、切后台、断链、服务退出的真实停止行为。根据最坏停止距离定速度和余量。
6. 分别验证前后与转身的覆盖；台阶、玻璃、负障碍不属于本轮平地模型的能力。

完成这些之后才能开放实机原生避障运动。此次没有复制或验证官方内部避障算法，也没有把模拟通过当成 PRO 实机支持结论。
