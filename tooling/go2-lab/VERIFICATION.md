# Go2 → Taku Phone 接入记录

日期：2026-10-24。设备为用户自己的 Go2 PRO；Android 为既有 TakuBase_API36_ARM64 / emulator-5554，API 36。网络为用户手机热点。

## 实测通过

- 通过 Taku Phone「机器狗」页面点击连接，Mac 桥接完成 WebRTC 认证。Android CLI 独立回读 `connected=true`。
- 两个真实状态主题持续更新：电量读数 87%，电压约 30.64 V，机身高度约 28.4 cm。这些是验证当时的读数，不是应用默认值或当前承诺。
- 通过 Android CLI 断开，随后 inspect 返回 `connected=false`、所有状态 `fresh=false`。
- 临时移除本功能的 ADB reverse，WebView 显示「Mac 服务未连接」「上次读数」，`data-live=false`；恢复 reverse 后重新通过 Android 工具发起连接，重新收到新鲜状态，最终页面电量 86%。
- 发送端计数只有 validation、状态订阅、rtc_inner_req 和 heartbeat；无 req/msg/运动主题。没有发送站立、走动、姿态或声音指令。
- APK 构建、签名验证与增量安装成功；已有应用及账号保留。新应用可在 Taku 的应用列表打开；本轮没有修改系统首页筛选规则。
- 安装 `taku-go2` 技能和 Android CLI，并从 Android 实际调用读取、连接、断开。没有宣称已验证模型自动选择该技能或语音交互。

## 离线与界面检查

- 只读协议与状态语义 4 项测试通过。
- HTTP 边界 4 项测试通过（使用假桥接，不访问机器人）。
- 现有 Node 测试 64 项通过。
- Android WebView 中文页面与连接/断开/服务不可达状态实测；当前设备视口及 320 / 768 / 1024 / 1440 宽度无横向溢出，中英文切换通过。
- 实测截图和原始状态在 ignored `out/go2-lab/`，没有把用户设备数据、APK、签名或运行依赖加入源码。

## 已知限制

Mac 服务、热点和 ADB reverse 需保持；没有开机自启、IP 自动发现、云端注册修复或 Android 独立 WebRTC 驱动。依赖社区协议，不保证未验证固件。权限限制在桥接服务，不以按钮是否可见作为动作权限。当前开发端口不能用于公网或多租户生产环境。


## 周围环境增量验证（同日）

- 接收 `rt/utlidar/voxel_map_compressed`，使用已固定版本驱动的 native 解码器。实测单帧约 4.4–4.5 万点，坐标系 `odom`，体素分辨率字段为 0.05 m；传到页面约 2800–3000 个抽样点。
- Taku Phone WebView 点击开始后显示真实点云，收到帧数持续递增。3D/俯视、复位、中英文切换通过；320/768/1024/1440 宽度无横向溢出，测试期间无 JavaScript 异常。
- 点击暂停：enabled=false、fresh=false、帧数停止增长，最后一帧保留并标记非实时。再次开始后新帧恢复。
- 临时移除 ADB reverse：点云页面显示「Mac 服务未连接」、data-live=false；恢复通道后自动恢复显示正在接收的数据。
- 固件时间戳实测为较粗的浮点数，多帧可相同。界面因此明确显示本机「最近收到」时间，不能把它解释为传感器精确采集时间。数据未更新超过五秒即过期。
- 新增的传感器白名单、点数上限、坐标保留和无效数据处理 3 项测试通过；HTTP 扩展后共 5 项、原只读协议 4 项通过。
- 发送端仅额外开放雷达 switch=on、disable_traffic_saving=on 和点云订阅/取消订阅。没有关闭雷达、修改姿态、发送运动或避障行走命令。暂停并不关闭狗自身的避障传感器。
- 本轮更新由既有 APK 加载 Mac 服务的新版页面，无需重装或清除账号。截图及检查输出在 out/go2-lab/lidar-*.png/json。
- 尚未实现狗位姿与点云配准、前后方障碍距离、物体语义识别或自动避障；自动居中展示不代表狗位于画面中心。


## 完整点云 WebGL 增量验证（同日）

- 替换前述 3000 点抽样路径：每帧有效坐标全部以小端 Float32 XYZ 传输，GPU 缓冲一次上传，单次 drawArrays(POINTS) 提交整帧。元数据独立保留，空白及无效数据不作可通行判断。
- 真实 Go2 + 同一 Taku Phone 测试：12 秒连续视角旋转期间，24 个采样点的本帧点数、上传点数、绘制点数逐项一致，为 64,282–64,357 点；无 JavaScript 异常和 WebGL 错误。另一次检查 GPU bufferBytes=776556，与 64,713×3×4 完全一致。
- 稳定绘制提交约 60 FPS；页面新点云上传约 4–7 Hz。12 秒采样区间内服务接收序号增加 87，页面上传帧数增加 63，说明最新帧策略会跳过中间旧帧，但保留选中帧的所有点。未宣称逐帧录制或雷达 60 Hz。
- 完整帧 HTTP 往返实测约 6.2–12.8 ms，含页面 fetch/arrayBuffer 完成，不包含传感器采集、狗到 Mac 的传输或屏幕呈现延迟。固件时间戳精度不足，未给出端到端延迟结论。
- 原图形模式和直接 -gpu host 模式均遇到 WebGL1 blocklisted。使用当前 userdebug WebView 的图形兼容性覆盖后，实测 renderer 为 ANGLE (Google (Apple), Android Emulator OpenGL ES Translator (Apple M4 Pro), OpenGL ES 3.0)。AVD 配置和开发标志的作用范围、回退方法见 README；不是任意 Android 设备的兼容性保证。
- 暂停后 fresh=false、enabled=false、帧数停止增长；恢复后继续接收。3D/俯视、复位、中英文与 320/768/1024/1440 宽度检查通过。临时断开 ADB reverse 后正确显示服务离线，恢复通道后重新显示实时数据。
- 模拟 WebGL context lost 后显示无法启用 WebGL，禁用开始按钮并标记非实时；恢复 context 后重建程序/缓冲，重新完整绘制，gl.getError()=0。
- 只读协议测试 4 项、HTTP 边界 6 项、全量点云/二进制/帧标识测试 5 项通过；三个 JavaScript 文件语法检查通过。Web 代码增量无需重建 APK。
- 没有修改发送端白名单，也没有发送站立、行走、姿态、声音或自主避障命令。
- 原始验证输出：out/go2-lab/webgl-performance.json、webgl-context-recovery.json、lidar-controls.json、lidar-offline.json；界面截图 webgl-full.png / webgl-final.png。全部保存在 ignored 输出目录，不提交用户设备数据。


## 手动微动增量验证（同日，用户重新授权运动）

- 用户明确要求前/后/左/右小幅动作，并确认已站稳、周围空旷且人在旁边。后续明确授权切换 normal 模式；这些授权覆盖本次测试，不构成未来自主行走授权。
- 固定参数前/后 ±0.08 m/s、左/右 ±0.15 rad/s、0.35 秒。后端不接受自定义速度或时长；一次 Move 后定时 StopMove，冷却两秒，启用 60 秒后失效。默认锁定，停止与异常会撤销启用。
- 首次驱动字段错误在发送 Move 前失败；修正为实际 driver.datachannel.channel，增加驱动形状测试。没有因此发出运动消息。
- AI 模式下测试未见实际移动。只读模式查询返回 ai，经用户明确授权切换 normal，返回码 0；用户观察到站姿调整。连接阶段不自动切换模式。
- normal 格式的低速前进：Move 返回码 0、StopMove 返回码 0，随后用户明确反馈「往前走了」。同参数此前一次用户只观察到站姿调整；不能保证每次精确一脚或固定距离。
- 用户进一步要求点击轻微后退。实际从 Taku Phone 页面勾选、启用、点击一次后退，然后点击停止/锁定；Move 和 StopMove 返回 0，状态回报后向速度约 -0.077 m/s。用户随后明确反馈「它确实后退了」。结束时 armed=false、busy=false。
- 左/右固定向量、限速与动作时长已做离线逻辑检查及页面按钮接入，尚未实机执行，不能声称转角已校准。
- 页面中文/英文、320/768/1024/1440 宽度无横向溢出；默认四方向锁定，仅勾选不会自动启用。模拟 HTTP 响应验证启用、动作后冷却、停止请求失败后的警示/锁定以及可重试停止；模拟测试没有访问机器人运动接口。
- 实机数据在 ignored out/go2-lab/micro-*.json/png。图形、断网、实际位移和速度不以模型推断替代现场观察。
- 这是局域网开发控制，不是认证的安全控制器；本机进程与模拟器应用属于当前信任边界。网络或 Mac 进程失效时，不保证停止指令可达；没有机器人端独立安全控制程序。
- 最终离线验证：感知/状态边界 5 项、HTTP 边界 7 项、微动/停止/模式/驱动发送 10 项、完整点云 5 项通过；四个 JavaScript 文件语法检查通过。页面在状态请求挂起后禁用运动入口，仍可点击停止；防止周期重绘把旧状态误当成新数据。
