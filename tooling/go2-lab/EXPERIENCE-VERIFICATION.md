# 模拟服务体验验证

本轮在机器狗不在场的条件下，直接操作 `TakuBase_API36_ARM64 / emulator-5554` 中的机器狗应用。后端始终为 `source=simulation`、`realTransportLoaded=false`，没有连接或操作真实 Go2。

## 体验结论

连接模拟器、选择场景、开启并验证、确认来源、启用一次动作、查看结果、遇障碍阻止动作、停止锁定、录制回放和普通断网恢复均可使用。

除了接口自动化，本轮通过实际 WebView 的触控事件操作可见按钮，并检查 Android 屏幕截图；模拟场景下拉值由自动化设置后触发 change，点击应用仍使用触控。没有把程序直接调用后端当成用户按钮体验。

## 发现并修补

| 问题 | 改动与复验 |
| --- | --- |
| 模拟页仍称「机器狗实时状态」，底部要求同一网络 | 状态页、电量标签、标题、连接按钮、路径、微动确认和环境说明均区分模拟、实机、回放；回放状态不再出现未定义文案 |
| 场景选择在地图下方，需要滚动才看到 | 将场景放到地图前，地图说明折叠；当前手机 816 CSS px 高视口中，场景选择从 y≈796 移到 y≈330，首屏可操作 |
| 灰色方向按钮没有说明阻止原因 | 增加前后左右「有障碍／未检出障碍／无法判断」；已开启、待勾选、待启用各阶段给出下一步提示 |
| 动作很小，不易确认是否发生 | 显示本次模拟位移和转角；触控前进观察到约 3 cm，动作后重新锁定 |
| 选了新场景但没应用时容易混淆 | 显示当前生效场景与「尚未应用」；不暗中应用场景 |
| 模拟停止故障提示使用实体遥控器，恢复方法不清楚 | 明确提示先应用空旷场景解除模拟故障，再显式重试停止；保持停止失败锁定 |

俯视图 canvas 只在尺寸变化时重新分配缓冲，方向说明只在内容变化时更新，避免周期性重建同样的节点。没有改变运动参数、真实传输权限或后端几何判断。

## 实际操作证据

- 状态页断开，再触控连接，恢复模拟状态。
- 触控开启 → 确认 → 启用 → 前进，显示位移；随后控制锁定。
- 应用前方障碍：显示「前 · 有障碍」，前进禁用，后退允许；停止按钮随时可达。
- 完整点云两次各短时观察约 8 秒，源点数、上传点数、绘制点数均为 6,640；末段采样约 60 FPS、9–10 Hz、单次 HTTP 传输约 5–6 ms。仅为当前模拟场景短时观测，不是长期性能或实机端到端时延保证。
- 点云暂停保留最后一帧并提示已暂停，继续查看恢复更新。
- 关闭 Mac 模拟服务后，手机显示服务不可用、动作入口失效。此时强制停止并重新启动应用，显示原生重试页；重新启动 Mac 服务后实际触控重试按钮成功，进程没有崩溃，控制没有自动启用。
- 回放标为历史状态和录制读数，运动保持禁止；结束后才能连接。

自动化复验：`test-phone-simulation.mjs` **28 项通过**；完整 `npm test` **74 项通过**；`npm run check:go2` 通过。手机套件覆盖四个宽度和中英文，并新增来源文案、首屏场景入口、障碍解释、动作反馈和回放标签断言。

截图与读数保存在 ignored `out/go2-lab/experience/`，包括 `state.png`、`scenario-first-screen.png`、`movement-feedback.png`、`front-obstacle-explained.png`、`full-cloud-running.png`、`service-offline.png`、`cold-start-offline.png`、`walkthrough.json`。画布以 ADB 截图为准：当前 WebView 的 CDP 页面截图可能漏掉 canvas 合成层，不能据此判断手机实际画布为空。

## 尚未解决的独立问题

此前已记录的「移除连接通道后立即用 CDP 强制重载」偶发 WebView 原生崩溃，未在本轮修复。普通服务中断、离线冷启动、原生重试通过，不能代替该压力场景。详见 [集成验证报告](SIMULATION-VERIFICATION.md)。

模拟通过仍不代表真实机器狗的原生避障兼容性或安全性能；实机避障运动入口继续关闭。
