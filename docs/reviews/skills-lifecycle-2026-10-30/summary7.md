## Unfinished work

Plugin upgrade, rollback, automatic failure rollback, journaled uninstall recovery, cross-process exclusion, and CLI/GUI integration remain unimplemented; required ≥50-round concurrency probes and interruption injection did not run. Native install writes cache before configuration, and uninstall removes cache before configuration; independent app-servers can write the same storage, so broker queues/client wrappers alone cannot guarantee cross-process transactions.

MCP privilege reduction and adversarial tests are unimplemented. Upstream stdio launch lacks plugin-origin identity; provenance, Android isolation services, and controlled IPC must be connected, then credentials, files, network, descendants, and resource limits tested on-device. Third-party MCP still has root-runtime permissions. Basic startup of a source artifact proves neither security isolation nor production fitness.

Do not merge the PR or call experimental builds/existing CLI baselines completed lifecycle functionality for this round.
