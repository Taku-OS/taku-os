Why Hi failed earlier

Earlier tasks timed out or were interrupted; the phone was then found to have no default network. Restoring connectivity exposed incorrect restoration of an old empty conversation: a conversation without its first turn has no resumable underlying history. The client now checks that a conversation is loadable before sending launcher messages; new conversations start their first turn directly, and invalid empty conversations open a new conversation while preserving the old record.

After default-network detection failed, Android permanently excluded the saved Wi-Fi from auto-connect. The connectivity-check URL was changed to one returning 204 on site, and the saved-network connection state was restored.

Real-model phone-tool calls also passed

The model actually ran two getprop commands, both exiting 0, read Android 16 / Pixel 9, and completed its reply. This check followed local-phone proxy setup and cold-boot recovery.

Updating away from the computer

UI / Agent APK:An APK with the same signature and a higher version code can be installed as an update on the phone without reflashing the entire system each time.

System / kernel / partitions:Build the corresponding images or OTA, then install through recovery or a configured update channel.

There is no signed OTA publication service or phone update channel yet. Source includes a FlClash preinstallation option for personal images, but the complete ROM was neither rebuilt nor flashed this round.

Still check before leaving

Verification used Wi-Fi and removed the computer-proxy dependency. No ready SIM was detected; cellular networking and travel-hotspot switching have not been tested.

For normal use, keep FlClash running and connect to working Wi-Fi, a hotspot, or activated mobile data. If the local proxy port changes, keep the Agent proxy address consistent.

The FlClash 0.9.0 startup notice prohibits commercial bundling, so the preinstallation switch currently applies only to personal Pixel builds. Commercial distribution requires a separate review.
