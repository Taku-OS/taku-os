# Historical language evidence

Public narrative reviews, authored research data, and HTML reports are in English. The files listed below intentionally preserve Chinese-language historical evidence or regression inputs. They are not default product text and have not been translated into fictitious English execution output. Their source bytes were checked against the release-preparation baseline; SHA-256 values are in [the machine-readable register](historical-language-evidence.json).

Memory experiments deliberately used Chinese synthetic timelines and model replies, including names, places, monetary amounts, and prompt-sensitive assertions. Other records include actual Chinese UI observations, third-party app compatibility findings, generated source, and test output. Repeated JSON records, failures, command output, identity, dates, and hashes remain intact. English README reports explain the complete procedures, results, manual intervention, and limits; they do not reclassify historical passes or imply a new test run.

Historical Chinese-origin app names, source URLs, locations, time zones, and model identities are factual provenance. English narratives transliterate or translate those names while preserving their identity. This retention does not make them current runtime defaults.

The hash-indexed [app compatibility report](../../evidence/api-inventory/historical/app-compat/compatibility-report.json) has a [complete English translation](../../evidence/api-inventory/historical/app-compat/compatibility-report.en.json). Other hash-indexed artifacts retain their original data. The scope in [historical-index.json](../../evidence/api-inventory/historical-index.json) means only files/content were reviewed; modification times are not execution times.

Two deliberately retained Chinese document versions are [Memory content](taku-memory-content-2026-10-22/README.zh.md) and the [daily-app summary](taku-memory-daily-apps-2026-10-22/README.zh.md); their default README files are English. Screenshots/video and text inside them remain original observations, not localized reproductions.
