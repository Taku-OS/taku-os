# Third-party materials, brands, and asset provenance

This inventory supports open-source readiness review, using baseline `8506bd2dfda09fd4087bda506badf798e1af9cc1`, compiled on 2026-11-06. It draws from existing source locks, licenses, notices, import records, and build settings. **It is not a complete SBOM, a per-file rights determination, or a complete release-package audit.** Licenses in the tables are declarations recorded in the linked files. This review did not revalidate every upstream website, dependency tree, or artifact.

The root [LICENSE](../LICENSE) applies Apache-2.0 to original work; it does not relicense third-party materials. See [open-source scope](open-source-scope.md). Upstream licenses, brand permissions, asset provenance, and inclusion of notices in final products are recorded separately. Downloadable sources or hashes do not establish all distribution rights.

## Review delivery order

1. Maintainers and design-asset rights holders confirm public rights for original work, design packages, brands, generated characters, and references; unclear origins remain pending review.
2. Separately inventory actual included files, source versions, modifications, and bundled notices for selected source/APK/ROM releases. Complete corresponding source and build deliveries for derived components such as the input method, going beyond direct dependencies.
3. Inspect actual licenses and notices in APK/ROM/runtime archives, not merely the presence of text in the repository. Font/design-system license directories and Codex's executable-only packaging especially need artifact-level confirmation.
4. Manually review screenshots, videos, and attachments selected for publication, checking personal data, third-party screens, and brand scope. Separately scan selected history and artifacts for secrets.

This batch only adds documentation and corrects screenshot tracking notes. It changes no licenses/notices, relicenses no assets, modifies no product packages, downloads no third-party artifacts, and operates no devices.
