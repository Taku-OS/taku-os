# Dynamic Island guide illustrations

Approved bilingual illustrations generated with ImageGen on 2026-11-24. These are explanatory
design illustrations, not device screenshots or pixel-exact specifications. Each depicted phone
or independent capsule has one camera; the capsule wraps its cutout with concave connections.

Each topic has a `.zh-CN.png` and `.en.png` edition. Use the matching document language.

| File stem | Content |
|---|---|
| `interaction-flow` | App → Home capsule → expanded card → app detail |
| `activity-switch` | Expand, collapse, select the waiting activity on the left, expand again |
| `swipe-and-hide` | Swipe left to switch; swipe right to hide, without ending the service |
| `capsule-anatomy` | A graphic + one protected camera + B information component |
| `compact-examples` | Recording timer and flight gate as independent capsule examples |

The user-supplied references informed the white background, layout and visual style. Taku's
actual interaction rules govern the diagrams: capsules and cards are mutually exclusive, the
waiting disc is on the left, and reversing a swipe does not restore a hidden notification.
