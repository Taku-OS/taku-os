## Acceptance order and current status

This document preserves the historical preparation plan for pinned `1199de2`; it is not evidence that current `main` is flashed or has completed physical-device upgrading. The later complete internal candidate `20261028112718` passed image inclusion checks for five Google apps, OTA/payload/AVB signature verification, export, and independent archive review; see [internal candidate acceptance](internal-google-apps-2026-10-28.md). That candidate was compiled from `778ce07` and excludes later `main` fixes `815cbac` and `be4824c`; UI screenshots, Pixel startup of that ROM, and data-preserving upgrading remain unaccepted.

The original acceptance order follows. Missing device validation must still complete these gates; passing P or offline-candidate records cannot be borrowed.

1. Verify public resources and the source closure; run version/snapshot negative tests, host protocol checks, and Android APK compilation.
2. Calculate actual remaining space on the Mac mini and Docker sparse disk; retain source volumes, kernel/compiler caches, old artifacts, failure records, and immutable snapshots.
3. Reuse caches through the existing controlled rebuild; complete real OTA/payload/AVB signature verification and export of the new image, then pin the P→target plan.
4. Before phone installation, recheck source, idle state, and selected Google-account/app data; save new backups and before evidence. Complete the loop with real native-updater installation, callbacks, target boot, and after evidence.
5. Check the new UI's conversations, floating windows across apps, expansion/collapse/dragging, keyboard avoidance, and matching broker; check GApps, default assistant/input method, selected account/configuration/workspace data, and another normal restart.

The user authorized this build and incremental OTA. It does not wipe data, unlock, manually change slots, resume Android 17 automation, or automatically publish to public channels. Original backups, account tokens, and configuration remain only in ignored local acceptance directories.
