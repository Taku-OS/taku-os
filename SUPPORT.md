# Getting help

Use the [public documentation](https://docs.taku.ai/) for installation, Agent, plugin and troubleshooting guides. Report ordinary issues without personal information in the [Taku OS community repository](https://github.com/Taku-OS/taku-os-plugins/issues). Implementation issues can also be reported in this repository.

Include the product version, full build number, device model, reproduction steps, expected and actual behavior, and minimal redacted logs. For download or upgrade issues, include both the source and target builds. Do not submit accounts, conversations, private keys, complete userdata images or raw sensitive logs.

Report vulnerabilities through the private route in [SECURITY.md](SECURITY.md). Taku OS is a development preview; the corresponding [release manifest](docs/releases/tokay-20261111080323.json) defines supported devices and tested scope.
