# Getting help

Use the [public documentation](https://docs.taku.ai/) for installation, Agent, plugin and troubleshooting guides. Report Taku OS core, ROM and emulator issues without personal information in [this repository's Issues](https://github.com/Taku-OS/taku-os/issues), and community plugin issues in [Taku-OS/taku-os-plugins](https://github.com/Taku-OS/taku-os-plugins/issues).

Include the product version, full build number, device model, reproduction steps, expected and actual behavior, and minimal redacted logs. For download or upgrade issues, include both the source and target builds. Do not submit accounts, conversations, private keys, complete userdata images or raw sensitive logs.

Report vulnerabilities through the private route in [SECURITY.md](SECURITY.md). Taku OS is a development preview; the [latest release manifest](docs/releases/latest.json) defines supported devices and tested scope.
